Academic Projects

Machine Learning Stock Trading Strategy Optimizer

  • Python

A simulator that uses reinforcement learning to train an agent to trade stocks based on certain indicators. The agent learns buy and sell signals based on historical data, using a custom reward function to maximize profit. The simulator allows for testing different trading strategies and visualizing the results.

Computer Vision IQ Test Solver

  • Python

A computer vision based application that utilizes a set of heuristics combined with pixel evaluation techniques to determine a pattern in a set of images and propose the next expected image.

Attention-based Key-Value Memory Network QA System

  • Python

An attention-based question and answer language model that makes use of a key-value memory network (stored information that isn't ingrained into the neural network in the form of key-value pairs) thus allowing for modification to the models knowledge without retraining the model. Keys are selected as an answer to a question based on an attention-scoring mechanism and cosine similarity.
